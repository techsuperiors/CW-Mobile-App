## WFH APIs

### Get User Profile (Extended)

- **Variable Name:** `getUserProfileExtended`
- **Endpoint:** `/api/users/profile`
- **Method:** GET
- **Purpose:** Fetch user WFH details
- **Returns:**
    - Half-day WFH
    - Single-day WFH
    - Multiple-day WFH
  
- **Used flutter_map for free opening of maps in the dialog in visit management**
